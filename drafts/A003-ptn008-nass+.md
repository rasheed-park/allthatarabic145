## 지문 (6)

### ① 자와드 수정  `nass+` · **LEV** · 확장형
```
مَرْحَبَا يَا جَوَاد، إِنْتَ مْنِيح؟
أَهْلَيْن يَا هَيْثَم، أَنَا مْنِيح.
```
- **korean**: 안녕하세요, 자와드. 잘 지내요? / 반가워요, 하이삼. 잘 지내요.
- **note**: `marḥabā yā jawād, inta mnīḥ? / ahlayn yā haytham, anā mnīḥ`
- **lahja**: LEV · **ح↔ه**: مرحبا(ح) ↔ أهلين·هيثم(ه)
- **수정 근거**: 기존 row298 의 `مَرْحَبْتَيْن`은 학습 표현 목록에 없음 → 배운 `أَهْلَيْن`(006,LEV)으로 교체. "대답+어서와" 응답 구조 완성, 범위 위반 해소.

### ② `nass+` · **MSA** · 기본형
```
مَرْحَبًا يَا بَدْر، كَيْفَ الْحَال؟
أَهْلًا! أَنَا بِخَيْر، الْحَمْدُ لله.
```
- **korean**: 안녕하세요, 바드르. 잘 지내세요? / 안녕하세요! 잘 지내요, 알함두릴라.
- **note**: `marḥaban yā badr, kayfa al-ḥāl? / ahlan! anā bikhayr, al-ḥamdu lillāh`
- **lahja**: MSA · **ح↔ه**: مرحبا·الحمد(ح) ↔ أهلا(ه)

### ③ `nass+` · **MSA** · 기본형
```
مَرْحَبًا، هُوَ جَدِيد هُنَا؟
أَهْلًا، هُوَ مُدِير جَدِيد.
```
- **korean**: 안녕하세요, 그분 여기 새로 왔어요? / 어서 오세요, 그분 새 매니저예요.
- **note**: `marḥaban, huwa jadīd hunā? / ahlan, huwa mudīr jadīd`
- **lahja**: MSA · **ح↔ه**: مرحبا(ح) ↔ هو·هنا·أهلا(ه)

### ④ `nass+` · **LEV** · 확장형
```
مَرْحَبَا يَا هَانِي، إِنْتَ جَاهِز؟
أَهْلَيْن! أَه، أَنَا جَاهِز.
```
- **korean**: 안녕하세요, 하니. 준비됐어요? / 반가워요! 응, 준비됐어요.
- **note**: `marḥabā yā hānī, inta jāhiz? / ahlayn! ah, anā jāhiz`
- **lahja**: LEV · **ح↔ه**: مرحبا(ح) ↔ هاني·جاهز·أهلين(ه)

### ⑤ `nass+` · **GLF** · 기본형
```
مَرْحَبَا يَا زِيَاد، إِنْتَ زَيْن؟

```
- **korean**: 안녕하세요, 지야드. 잘 지내요? / 어서와요! 네, 잘 지내요.
